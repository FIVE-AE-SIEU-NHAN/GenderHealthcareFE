
## Lần chạy lúc 03:12

This update introduces a major new **Profile Management feature for consultants**, significantly overhauls the UI/UX of key forms, and refactors how page scrolling and date handling work.

### ⭐ Key New Feature: Consultant Profile Management
- A new **"Profile Management"** page has been added for the consultant role.
- The consultant's dashboard sidebar now includes a link to `/consultant/profile`.
- The `EditProfileForm.tsx` component has been made reusable, now capable of editing both regular user and consultant profiles.
- The profile update logic now correctly invalidates the cache for both user and consultant profiles, ensuring data stays consistent.

### 🎨 Major UI/UX Enhancements
- **Create User & Edit Profile Forms:**
    - Both forms (`CreateUserForm.tsx`, `EditProfileForm.tsx`) have been redesigned with a modern card-based layout, complete with titles, descriptions, and icons.
    - User input fields have improved styling and subtle animations.
    - Submit buttons now have a loading state (spinner icon) and an enhanced visual style (gradients, shadows).
- **Customer Profile Page (`Profile.tsx`):**
    - The "Edit Profile" action now opens a modal dialog (`Dialog`) for a cleaner and more focused user experience.

### ⚙️ Technical Improvements & Refactoring
- **Scroll-to-Top Logic Changed:** The `ScrollToTop.tsx` component (which automatically scrolled to the top on every page change) has been **deleted**. This functionality is now handled manually by adding an `onClick` event to the main navigation links in the `Navbar.tsx`.
- **Improved Date Handling:**
    - Forms now use a custom `NewDatePicker` component instead of the browser's default date input.
    - The form validation was updated to correctly handle `Date` objects instead of simple strings, improving data integrity and preventing potential bugs.

### 🔧 Other Changes
- A new `genlog` script was added to `package.json` to automate the generation of changelogs.
