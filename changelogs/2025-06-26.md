## Lần chạy lúc 04:12

This update introduces a major new **Consultant Management feature for Managers**, providing them with a comprehensive dashboard to view, filter, and manage consultant profiles. It also includes significant code quality improvements by centralizing constants and enhancing UI components.

### ⭐ Key New Feature: Consultant Management Dashboard

-   **New Page and Route:** A dedicated **"Consultants Management"** page (`/manager/consultants`) has been created for the Manager role.
-   **Sidebar Navigation:** A new link with a `ShieldUser` icon has been added to the manager's sidebar for easy access to the new dashboard.
-   **Comprehensive Data Table:** The page features a powerful data table (`ConsultantsList.tsx`) that displays detailed consultant information, including specializations, experience, and status.
-   **Full CRUD Support (Backend Ready):** The entire data layer for managing consultants has been built, including:
    -   A dedicated API service file (`manageConsultantApi.ts`) for all consultant-related network requests.
    -   Robust React Query hooks (`useConsultants.ts`, `useConsultantMutations.ts`) for fetching data and handling updates (status changes, profile edits).
-   **In-Place Profile Editing:** Managers can now click "Edit Profile" from a consultant's row action menu to open a dialog (`Dialog`) containing a form (`EditConsultantForm.tsx`) to update their specializations, certifications, and experience.

### 🎨 UI & Code Quality Enhancements

-   **Centralized Topic Constants (`topics.ts`):** The list of available topics (e.g., "Women's Reproductive Health") is now defined in a single, central file. A `style` property has been added to each topic, allowing for consistent, data-driven badge colors across the application.
-   **Refactored Question Lists (`QuestionList.tsx`):** Both the Consultant and Customer question list pages have been updated to use the new centralized `TOPIC_OPTIONS` constant for rendering topic badges, removing hard-coded styling logic and improving maintainability.
-   **Improved Filter Display (`TableToolbar.tsx`):** The main filter button now intelligently displays the user-friendly **label** of the selected filter options (e.g., "Online", "Admin") instead of the raw backend **value** (e.g., "Online", "Admin"), leading to a much better user experience.
-   **New Consultant Constants:** A dedicated constants file (`manager.consultantConstants.ts`) has been created to manage all status definitions and search field mappings for the new consultant feature.

### 🔧 Other Changes

-   The Manager's default dashboard page (`/manager`) has been correctly pointed to `ManagerDashboard.tsx`.
-   Minor layout adjustments were made to the `DataTable` header and `TableToolbar` search field for better flexibility and to prevent text wrapping.
